# FAQ

**Is it free?**
Yes. The code is MIT licensed. If it makes your game better, you can [support it on Ko-fi](https://ko-fi.com/clobbersoft). There's also a link in Settings → About and in the tray menu.

**Is this allowed by Blizzard?**
Comunimate is a normal add-on plus a separate program that types for you, like a keyboard would. It doesn't automate gameplay. Chat is sent the way WoW allows add-ons to send it. As with any add-on, use it at your own discretion.

**Does my voice go online?**
No. Speech recognition runs on your PC. The only download is the voice model, once, during setup.

**Which controllers work?**
Anything WoW: Forever supports: PlayStation 5 and 4, Xbox, Steam Controller and Steam Deck. The PS5 mic button is the default talk button; on other controllers pick one in Settings → Voice.

**I play with keyboard and mouse. Is it useful?**
Yes, for voice: set a **Talk key** (Settings → Voice), hold it, and talk.

**Can I use only the keyboard, without the helper?**
Yes. Install the add-on zip only. Everything but voice works.

**Does it work in other versions of WoW?**
It's made for WoW: Forever. Other versions aren't supported.

**Why does the voice model need 500 MB?**
That's the size of a good-quality speech model that runs fully on your PC.

**Can I make my own mascot art?**
Yes. See the [art guide](https://github.com/ClobberSoft/Comunimate/blob/main/art/ART_GUIDE.md).

**How do I report a bug or suggest something?**
[Issues](https://github.com/ClobberSoft/Comunimate/issues/new/choose).
