# Controls

Button names are PlayStation's. Xbox and Steam players see their own icons (Settings → General → Controller). **Every keyboard button can be remapped** in Settings → Buttons.

## Opening things

| Do this | Get this |
|---|---|
| **L1 + R1 + D-Down** | The full keyboard |
| **Hold the talk button** (PS5 mic by default) | The small "Listening to your wisdom" box (see [Voice](Voice)) |
| **Tap the talk button** | Open / close the keyboard |
| **Click your mascot** | Settings |
| `/cm` | Keyboard |
| `/cm options` | Settings |

## On the keyboard

| Button | Does |
|---|---|
| Left stick / right stick | Move the ring over the left / right half of the keys |
| **L2 / R2** | Type the key under the left / right ring |
| Cross | Space |
| Square | Delete (hold to repeat) |
| Triangle | Use the highlighted word suggestion |
| D-Left / D-Right | Pick a word suggestion |
| L1 | Shift (one letter) |
| D-Up | Caps lock |
| R1 | Numbers and symbols |
| D-Down | Change channel |
| Create | Clear the line |
| Options | Send |
| Circle | Close |

The button guide along the bottom of the keyboard always shows your current buttons.

## Stick styles

Settings → Sticks → **Stick style**:

| Style | How it feels |
|---|---|
| **Spring** (default) | Steer each ring precisely; it glides back to the middle key when you let go |
| **Free** | The ring stays wherever you leave it |
| **Snap** | The stick points straight at a key, no ring travel |
| **Swipe** | One keyboard, one ring, trace whole words; see [Swipe Typing](Swipe-Typing) |

## Channels

D-Down cycles: **Auto** (Instance / Raid / Party / Say, whichever fits your group), Party, Raid, Instance, Guild, Say, Yell, General, Trade, **Reply** (whispers back to whoever whispered you last; the label shows their name).

You can also start a message with a chat command: `/p`, `/ra`, `/i`, `/g`, `/s`, `/y`, `/1`, `/general`, `/trade`, `/w Name`, `/r`.

## Slash commands

| Command | Does |
|---|---|
| `/cm` | Open / close the keyboard |
| `/cm options` | Settings window |
| `/cm controller ps \| xbox \| steam` | Button icons |
| `/cm scale 0.5-2` | Keyboard size |
| `/cm reset` | Keyboard back to its starting spot |
| `/cm invert` | Flip stick up/down |
| `/cm voice on \| off` | Whether talking opens Comunimate |
| `/cm forget` | Erase learned words |
| `/cm debug` | Show button names and stick values (troubleshooting) |
